# AI-Powered Workforce Analytics Dashboard

## Overview

The **AI-Powered Workforce Analytics Dashboard** is an interactive web-based dashboard designed to provide workforce insights through visual analytics, key performance indicators, employee analytics, workforce trends, attrition analysis, performance monitoring, and AI-based insights.

The dashboard provides an interactive interface for exploring workforce metrics and viewing different analytical sections from a single dashboard.

---

## Features

### Workforce Overview
- Total employee count
- Active employee count
- Attrition rate
- Promotion rate
- Workforce health score
- Average tenure
- Average performance
- Attendance metrics
- Workforce trend analysis
- Gender distribution
- Workforce forecast

### Employee Analytics
- Employee-level analytics
- Department information
- Performance information
- Attendance
- KPI scores
- Promotion probability

### Performance Dashboard
- Performance distribution
- Department-level performance
- Performance trends
- Performance-related workforce metrics

### Attendance Dashboard
- Attendance analysis

- Overtime information
- Department-level attendance comparison

### Salary Dashboard
- Salary-related workforce analytics
- Salary distribution and comparisons

### Promotion Dashboard

### Attrition Dashboard
- Attrition rate
- Attrition trends

### Workforce Risk Radar

- Workforce risk indicators
- Risk-related analytics

### Top Performers
- Employee performance leaderboard
- KPI scores
- Attendance
- Promotion probability

### AI Insights Dashboard
- Model accuracy
- AUC score
- Active predictions
- Attrition prediction
- Workforce health analysis
- AI-generated workforce recommendations

## Technology Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Font Awesome
- Google Fonts
- Browser Local Storage

The dashboard is implemented as a self-contained HTML application. The charts are rendered using Chart.js, which is loaded through a CDN.
